To add conference photos, place the JPG files at the exact paths above.

To preview locally: double-click index.html, or run: python -m http.server 8000
then open http://localhost:8000

For GitHub Pages: create a GitHub repository, upload index.html and the entire assets folder, then Settings -> Pages -> Deploy from a branch -> main -> /root.

Important: the article links were supplied by the site owner. Exact publication dates for the links where the CV did not state a date were not independently verified in this build.
